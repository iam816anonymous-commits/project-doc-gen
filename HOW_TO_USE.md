# How To Use ReportReady

## Workflow: Generate Documentation from GitHub

1.  **Login**: Access the application and authenticate using your email and the OTP sent to your console/email.
2.  **Source Selection**: On the homepage or `/generate` page, select **GitHub Repo**.
3.  **Input URL**: Paste your GitHub repository URL (e.g., `https://github.com/user/repo`) and press Enter.
4.  **Automatic Analysis**: System extracts tech stack and modules.
5.  **Review Intelligence**: On the `/generate/review` page, verify the detected information (Title, Tech, Features).
6.  **Add Identity**: Enter your Name, University, and Academic Level.
7.  **Generate**: Click "Generate My Full Project Kit".
8.  **Preview**: View the partial report (Abstract and Objectives are free).
9.  **Unlock**:
    *   **Option A**: Click "Unlock Full Report (₹99)", follow the UPI payment instructions, and upload your screenshot.
    *   **Option B**: Click "Join Founding Program", submit detailed feedback (100+ chars), wait for Admin approval, and use your 1 Free Credit.
10. **Download**: Once unlocked, download your **PDF** and **DOCX** files from the project header.

## Workflow: Generate Documentation from ZIP/PDF/DOCX

1.  **Login**: Authenticate with Email OTP.
2.  **Upload**: Select **Upload ZIP**, **PDF**, or **DOCX**.
3.  **Analyze**: System parses the file content (adm-zip for ZIP, text-parsing for others).
4.  **Confirm**: Review detected metadata and add personal details.
5.  **Follow Unlocking Flow**: Same as GitHub workflow.

## Workflow: Contribute a University Template

1.  **Login**: Authenticate.
2.  **Contribute**: Use the contribution form (if visible) or upload an existing report during the generation flow.
3.  **Processing**: System extracts the formatting rules automatically.
4.  **Admin Review**: An administrator will review the extracted template in the Admin Portal.
5.  **Activation**: Once activated, future reports for that university will follow the new template.

## Workflow: Admin Verification

1.  **Login**: Access `/admin/login` and enter admin credentials.
2.  **Dashboard**: Navigate to `/admin`.
3.  **Payments**: View pending screenshots. Click "Approve" to unlock projects for students.
4.  **Feedback**: Review student feedback. Click "Approve & Reward" to grant free credits.
5.  **Templates**: Visit `/admin/templates` to approve and activate university formatting rules.
