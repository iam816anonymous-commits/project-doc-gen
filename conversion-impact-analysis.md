# Conversion Impact Analysis: Multi-Source Intake

## 1. Projected Funnel Improvement
By removing the "GitHub Only" constraint, we expect the following impact:
*   **Top-of-Funnel (ToF) Increase**: +300% (Majority of diploma and non-CS students do not use GitHub for academic projects).
*   **Landing Page Conversion (CVR)**: +40% (Users find a path that fits their current project state).
*   **Customer Lifetime Value (CLV)**: Increased through "Mini Project" support via ZIP/Manual entry.

## 2. Friction Reduction
*   **Technical Barrier**: Reduced from "Must know Git" to "Can upload a folder".
*   **Mental Barrier**: Reduced from "I need to code first" to "I can start with my draft report".

## 3. Revenue Projections (MVP Phase)
*   **GitHub Path**: ~20% of paid users.
*   **ZIP/Manual Path**: ~60% of paid users.
*   **Draft Path**: ~20% of paid users.

## 4. Risks & Mitigations
*   **Risk**: Low accuracy for ZIP uploads without clear structure.
*   **Mitigation**: Fallback to manual form for missing metadata.
*   **Risk**: Complex PDF parsing failures.
*   **Mitigation**: Text-area fallback for users to paste draft content if upload fails.
