# Field Classification Audit

## 1. Project Metadata
| Field | Classification | Extraction Method |
| :--- | :--- | :--- |
| Project Title | Auto Detect | Repo name, File name, or Content match |
| Tech Stack | Auto Detect | Manifest analysis (package.json, etc.) & heuristics |
| Modules | Auto Detect | Folder structure & file path analysis |
| Features | Auto Detect | Keyword & dependency frequency analysis |
| Database | Auto Detect | Config & library detection (e.g. Mongoose, Prisma) |
| Architecture | Auto Detect | Structural patterns (e.g. Client/Server, Microservices) |

## 2. Academic Context
| Field | Classification | Extraction Method |
| :--- | :--- | :--- |
| Student Name | **Required** | Manual Entry |
| University | **Required** | Manual Entry |
| Academic Level | **Required** | Manual Selection (Default: BTech) |

## 3. Contact Info
| Field | Classification | Extraction Method |
| :--- | :--- | :--- |
| Email | **Required** | OTP Authentication |

**Summary:**
By moving to an 'Analyze First' architecture, we have successfully removed **6+ manual entry fields**, replacing them with automated AI-driven extraction. The student now only provides their identity and academic institution.
